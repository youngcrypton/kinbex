## 1. Merging Social Interaction with Live Trading

In traditional crypto trading, community discussions occur in closed silos (Discord, Telegram, X Spaces) completely isolated from order execution. Kinbex synchronizes social interaction and execution into a unified communication grid.

---

## 2. Peer-to-Peer Floating Calls (WebRTC Overlay)

Kinbex features direct, browser-native voice and video communications powered by WebRTC:

* **Persistent Floating Picture-in-Picture (PiP):** Users can engage in 1-on-1 or small-group video and audio calls while navigating the terminal, tracking charts, auditing contracts, and executing swaps.
* **Low-Latency P2P Mesh:** Media streams travel directly between peers via **DTLS/SRTP** encryption, ensuring private, sovereign communications without centralized server recording.
* **Fallback TURN/STUN Relays:** Globally distributed relay nodes guarantee connection stability across strict enterprise NATs and mobile cellular connections.

## 3. Kinbex Live Audio Spaces

Decentralized multi-participant audio stages designed for project founders, token developers, and alpha callers to host interactive community town halls and AMAs:

* **Token-Gated Speaker & Listener Access:** Space hosts can configure entry requirements, such as minimum $KINBEX token holdings, specific NFT ownership, or verified caller leaderboard status.
* **In-Space Trade Tipping:** Listeners can tip speakers and alpha callers in real time using native cryptocurrency tokens or $KINBEX.
* **Integrated Token Ticker Banners:** Space hosts can pin a token contract directly to the space header, allowing all participants to chart and swap simultaneously while listening.
